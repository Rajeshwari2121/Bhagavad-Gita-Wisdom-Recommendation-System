# 🦚 Bhagavad Gita Wisdom Recommendation System

An interactive multilingual Bhagavad Gita learning and recommendation application developed using Python and Streamlit.

## Features

- 18 selectable life problems with relevant Bhagavad Gita teachings
- Complete featured Sanskrit shlokas displayed in Devanagari and Telugu scripts
- Meanings and explanations in English, Hindi, and Telugu
- Summaries of all 18 chapters
- Krishna–Arjuna devotional artwork with gentle animations
- Interactive analytics dashboards using Plotly
- Bhagavad Gita knowledge quiz
- Daily wisdom and practical guidance

## Technologies

Python, Streamlit, Pandas, Plotly, Scikit-learn, HTML and CSS.


## Purpose

To make Bhagavad Gita teachings accessible through multilingual explanations, interactive exploration, and practical reflections on everyday life challenges.
